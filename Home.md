# About Enlightenment

*Enlightenment is a Window manager, Compositor and low memory Desktop
Environment for X11 and Wayland (experimental).*

## Minimal

Comparing to similarly featured desktop environments (with compistors,
file managers, a full range of desktop management tooling and similar
features), Enlightenment comes in by far the smallest. It's in the
same realm as minimal environments like LXDE but with significantly
more features. If you want minimal with all the bells and whistles,
Enlightenment has it.

## Features

* Window management with extensive controls and customization
* Compositing to make the UI more polished and smooth
* OpenGL accelerated compositing as well as dedicated sofware rendering
* Control over animation speed to have it be faster or slower
* Battery status display and plug/unplug notifications
* Battery history display
* CPU usage and frequency display
* CPU Power management controls
* Digital and analog clocks and calendar
* Shutdown, reboot, suspend and hibernate (hybrid etc.) controls
* Audio mixer/volume controls
* Audio device selection
* Audio I/O VU meters and active application display
* Per window volume controls in the titlebar
* Full detailed audio mixer controls
* Music control of player apps via MPRIS2
* Bluetooth control (for BLuez5)
* Network (wifi, wired, tethering etc.) via connman
* Keyboard layout and layout switching
* Temperature display for one or more sensors
* Quick launching icon bar
* Virtual desktop pager with live desktop displays
* Multi-resolution wallpers
* Animated wallpapers (gif, videos etc.)
* Backlight controls (desktop via DDC and laptop built-in)
* Built in screenshotting, cropping, editing and sharing on-line
* Tiling layout options like tiling window managers
* File manager
* Quick launcher/window finder/calculator/file browser
* Desktop gadgets
* Multiple gadget shelves
* Polkit support
* Desktop notifications
* System tray (status notification protocol)
* Global scaling controls
* Themes
* Palettes
* Screen lock
* Fingerprint support for screen lock
* Screen blanking controls
* Touchpad esture support
* Keyboard shortcut bindings
* Mouse bindings
* Screen edge/"hot"corner bindings
* Multiple screen resolution and layout controls
* User language controls
* Multiple profile support
* Extensive pluggble module system for extending
* Font controls
