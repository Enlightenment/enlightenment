# About Enlightenment

*Enlightenment is a Windowmanager, Compositor and low memory Desktop
Environment for X11 and Wayland (experimental).*

## Minimal

|---------------|--------|-|
| Enlightenment | 124M   | |
| XFCE          | 225M   | |
| GNOME         | 425M   | |
| KDE           | 475M   | |
